## 🛠️ Tech Stack & Architecture

- **Core:** Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling:** Custom Vanilla CSS3 (Glassmorphism, CSS variables, fluid responsive layouts)
- **Visuals & Animations:** HTML5 Canvas particle background, CSS micro-interactions, custom cursor
- **Icons & Typography:** FontAwesome 6, Google Fonts (`Outfit`, `Space Grotesk`, `Space Mono`)
- **SEO & Discoverability:**
  - Semantic `<meta>` tags (Title, Description, Keywords, Robots)
  - Open Graph & Twitter Cards for rich social sharing previews
  - Schema.org (`Person`) JSON-LD structured data for Google Knowledge Graph
  - XML Sitemap (`sitemap.xml`) & `robots.txt`
